## Historia
Como **visitante que toma el diagnóstico** quiero **ver bien dibujadas las fórmulas y el código de las preguntas** para **entender lo que se pregunta sin leer signos de pesos ni comandos sueltos**.

## Contexto
- **Tipo de usuario:** Tareas técnicas
- **Corte propuesto:** Corte 1 (MVP)
- **Épica:** E1 Diagnóstico y captura de leads
- **Origen:** refinamiento de HU-009 (5-oct-2026). `scripts/contenido/matematica.mts:7` deja la conversión de cada `$…$` a MathML a quien dibuje las preguntas, pero ningún criterio de HU-009 lo pedía. Física II tiene 8 líneas con fórmulas e Introducción a la Programación tiene 11 bloques de código cercados: sin esta HU, la primera pregunta de circuitos sale con signos de pesos y llaves a la vista.
- HU-009 depende de esta HU. HU-022 y HU-039 la reutilizan si muestran preguntas.

## Criterios de aceptacion
- [ ] Dado un texto con `$rac{1}{R_{	ext{eq}}}$`, cuando se dibuja, entonces sale una fracción apilada con subíndice y no el texto crudo.
- [ ] Dado cada comando de la lista `COMANDOS_MATE` (`scripts/contenido/matematica.mts`), cuando se dibuja, entonces no queda ningún comando sin convertir. Una prueba compara la lista del dibujo con la del convertidor, para que no se desfasen.
- [ ] Dado un `\$`, cuando se dibuja, entonces sale un signo de pesos y no abre una fórmula.
- [ ] Dado un `$` sin cerrar o una fórmula que no se entiende, cuando se dibuja, entonces sale el texto tal cual y la pantalla no falla.
- [ ] Dado un bloque de código cercado en un enunciado, cuando se dibuja, entonces conserva la sangría y todo es literal; si es más ancho que la pantalla, tiene scroll dentro del bloque, se alcanza con el teclado y la página no tiene scroll horizontal.
- [ ] Dado un celular de 390 px o un escritorio de 1280 px, cuando se dibuja una fórmula, entonces su texto, incluidos los subíndices, mide 14 px o más.
- [ ] Dado un enunciado, una opción, un texto de error o una descripción, cuando se dibuja, entonces el componente es el mismo para todos y nunca usa `innerHTML` con texto del banco.

## Fuera de alcance
- El carril lateral de escritorio del prototipo (un indicador de pasos desde 1200 px de ancho).
- Mostrar preguntas en pantallas concretas: lo hacen HU-009, HU-022 y HU-039.

## Notas tecnicas
- Portar el dibujo del `index.html` del prototipo (`dvarela5101/Calibra`, rama `main`): `partirMate`, `analizarMate`, `mml`, `anexarFilaMml`, `matematica` y `partirEnunciado`. El bloque de código del prototipo es un `<pre>` con `tabindex="0"`, `role="region"` y `aria-label="Código"`, escrito con `textContent`.
- Noto Sans Math, que HU-001 dejó para esta HU (`backlog/HU-001.md`).
- MathML baja los subíndices por defecto (`math-depth`). Hay que comprobar los 14 px en un navegador y, si no llegan, sobrescribirlo o subir la base.
