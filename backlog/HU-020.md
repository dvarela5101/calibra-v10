## Historia
Como **admin** quiero **revisar cada pago que me asignan contra su comprobante** para **confirmar que el dinero llegó antes de que se le pague al monitor**.

## Contexto
- **Tipo de usuario:** Admin
- **Corte propuesto:** Corte 1 (MVP)
- **Épica:** E6 Pagos y verificación, E12 Administración
- **Reglas:** RN-41, RN-42, RN-43, RN-44, RN-45. Flujo F3.
- **Decisiones (29-sep-2026):** P-24: si el admin rechaza un pago después de que la sesión se realizó, la monitoría no se cancela: ese pago queda fuera del desembolso (RN-45) y el admin registra el caso para cobrarlo por fuera o asumirlo. El monitor ve el estado del pago en su agenda ([HU-021](HU-021.md)).

El admin asignado tiene 1 hora. Un pago rechazado no se reembolsa.

**Frente a la app actual.** No existe.

## Criterios de aceptacion
- [x] Dado un pago asignado, cuando el admin lo abre, entonces ve comprobante, monto, pagador, contacto, referencia, monitoría y tiempo restante.
- [x] Dado un pago en revisión, cuando lo aprueba, entonces queda `aprobado` con fecha de revisión.
- [x] Dado un pago de una individual que aún no se realizó, cuando lo rechaza, entonces el pago queda `rechazado`, la monitoría pasa a `cancelada` (`pagoRechazado`), la fecha se libera y se avisa al pagador por su contacto.
- [ ] Dado un pago de una grupal, cuando lo rechaza, entonces solo se anula ese cupo y se avisa al pagador para que lo intente de nuevo (aplica desde [HU-038](HU-038.md)).
- [x] Dado un pago rechazado, cuando se consulta, entonces no tiene reembolso.
- [x] Dado un pago, cuando el admin abre su comprobante, entonces lo ve con un enlace firmado que se pide en ese momento y dura 60 segundos ([HU-007](HU-007.md)).
- [x] Dado una monitoría ya realizada, cuando el admin rechaza uno de sus pagos, entonces la monitoría sigue `realizada`, el pago queda fuera del desembolso y el caso queda registrado para cobrarlo o asumirlo (P-24).

## Fuera de alcance
- Escalamiento automático ([HU-034](HU-034.md)).

## Notas tecnicas
Cuando existan las grupales, el rechazo del primer pago de una grupal depende de P-06 (se refina en [HU-036](HU-036.md)).

## Definicion de terminado
- [x] Criterios de aceptacion cumplidos
- [x] Pruebas pasan
- [x] Sin cambios fuera de alcance
