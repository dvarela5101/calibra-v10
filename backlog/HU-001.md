Recomendación a confirmar: Next.js (App Router) con TypeScript en Vercel; Supabase para Postgres, Auth (con inicio anónimo), Storage, Realtime y tareas programadas; Vitest para lógica y Playwright para flujos.

**Frente a la app actual.** El prototipo es un solo `index.html` (unas 8.200 líneas) sin build ni frameworks, con reglas como "nada de localStorage" que el arnés verifica. Esas reglas impiden la sesión persistente (RN-10) y el login. La reconstrucción va en un repo o carpeta nueva; el repo actual queda como referencia de solo lectura. Se rescata: `contenido/*.md` y `convertir.js`, la lógica del diagnóstico por knowledge components, la Edge Function `enviar-correo` (plantillas y pruebas), los tokens de diseño y las reglas de accesibilidad (texto de 14 px o más, áreas táctiles de 44 px, contraste AA, sin degradados ni iconos de IA).

## Notas tecnicas
Se recomienda un proyecto Supabase nuevo (o un esquema nuevo): `supabase/schema.sql` del prototipo empieza con `drop table ... cascade` y el modelo cambia por completo. El proyecto `uotlhaitdkfroavqkvee` queda como fuente de datos históricos.

Implementación (2026-09-28):
- Next.js 16.3.6 (App Router, `src/`), TypeScript, ESLint, sin Tailwind: los tokens del prototipo viven como variables CSS en `src/styles/tokens.css`, igual que en `index.html`.
- `npm run inicio` = `npm install` + `next dev` (un solo comando tras clonar). `npm run verificar` corre lo mismo que el pipeline.
- Regional: `src/config/regional.ts` (America/Bogota, `es`, `es-CO`); `src/lib/fechas.ts` formatea siempre en esa zona.
- Pruebas: Vitest (`src/**/*.test.ts`, `pruebas/`) comprueba zona horaria, contraste AA de los tokens y que no haya secretos versionables; Playwright (`e2e/`, 390x844 y 1280x800) comprueba la página de inicio en español, sin errores de consola, sin scroll horizontal, texto de 14 px o más y sin degradados.
- CI: `.github/workflows/ci.yml` (verificar → desplegar con la CLI de Vercel; preview comentado en cada PR). `vercel.json` apaga el despliegue automático por Git para que solo despliegue el pipeline. Sin los secretos `VERCEL_TOKEN`, `VERCEL_ORG_ID` y `VERCEL_PROJECT_ID`, el despliegue se salta con aviso.
- No se portaron el carril lateral de escritorio (`--carril`, `--banda`...) ni Noto Sans Math: se traen con las pantallas que los usan (diagnóstico, HU-009).
